Main goal :- 
Is to analyse stock market trends , fetch data of real market compare historical numerical data by using yahoo finance (yfinance) to find trends , risk , daily returns , volatility etc 
And also it will suggest stocks for investment using these parameters.

Basic Flow:- user stock symbol → yfinance  → real market data → numpy arrays → data analysis → final report → suggest stocks 

Why Are We Building This Project? 
main purpose is to understand  M.L libraries (Numpy , pandas , matplotlib , streamlit etc)

Uses of Numpy :- Given historical market data, analyze the stock's price behavior, returns, volatility, trend and other statistical characteristics using NumPy .
